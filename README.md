# Phone Book (C++)

A console-based contact manager written in C++ as a first-year programming assignment, using object-oriented programming.

## Features
- Add, view, search and delete contacts
- Stores name, phone number, email, address, birthday and notes
- Saves contacts to a text file

## Concepts used
Classes and encapsulation (getters), vectors, file handling with `fstream`, input validation, menu-driven program flow

## Run
```bash
g++ phonebook.cpp -o phonebook
./phonebook
```
